# Aimaker Google Play upload checklist

1. Create the app in Play Console with default language English (United States), app name `Aimaker: AI Product Creator`, app/game = App, and free/paid = Free.
2. Enroll in Play App Signing and upload the signed `Aimaker-release.aab`.
3. Use package name `tech.aimaker.app`. This cannot be changed after the first release.
4. Add privacy policy `https://aimaker.tech/privacy` and support email `ai@tyrveai.com`.
5. Copy the supplied title, descriptions, and release notes from `play/listing/en-US/`.
6. Upload a 512×512 PNG app icon, 1024×500 feature graphic, phone screenshots, and optional tablet screenshots.
7. Complete App access with a reusable reviewer login if authentication blocks core features.
8. Complete Ads = No, Content rating, Target audience, News apps, Data safety, and account-deletion declarations accurately.
9. Add a working public website account-deletion URL.
10. Upload first to Internal testing; test sign-in, uploads, generation, downloads, deletion, and purchases/credits.
11. If the developer account is a newly created personal account, complete Google's required closed test before production access.

The app targets Android 16 / API 36, meeting the Google Play requirement applying from August 31, 2026.
